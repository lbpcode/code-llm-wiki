# Changelog

## v0.1.0

- Establish a Process-centric, multi-repository Code LLM Wiki.
- Define QNX, Android, and Linux-TBOX as the first-phase Platform Profiles.
- Bind deployment context to Platform Profile instead of creating an unrestricted OS/product matrix.
- Define separate System-level and Process-level knowledge.
- Add source evidence, commit provenance, and profile-scope requirements.
- Include optional CMake Graphviz DOT as build-dependency input.
- Defer AST extraction to a later phase.
- Define strict quality gates: structural/provenance checks, independent LLM review, and human approval.
- Provide portable Skill/Prompt workflows without a custom TypeScript runtime.
