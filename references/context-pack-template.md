## Explicitly excluded context

- Hidden reasoning or unpersisted conclusions.
- Unrelated Task Reports and source files.
- Source excerpts already represented by exact Evidence locators, unless a small excerpt is essential.
- Completed tasks that do not affect the next task's acceptance criteria.

The Checkpoint remains authoritative if this pack conflicts with it. If source revisions or the Wiki base do not match, stop and reconcile before continuing.
