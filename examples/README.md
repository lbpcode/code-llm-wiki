# Examples

This directory will contain synthetic examples illustrating the Wiki schema and Skill outputs.

Examples must remain clearly labeled as illustrative. They must not be presented as facts about the actual QNX, Android, or Linux-TBOX system.

Planned examples:
- A process implemented by one repository and deployed on two profiles.
- A process spanning more than one repository.
- An IPC interface with provider/consumer evidence.
- A startup workflow scoped to one Platform Profile.
- A CMake target dependency that is explicitly not a runtime dependency.

Real project names, repository URLs, commit SHAs, source paths, permissions, and architecture details may only be added from inspected source repositories.
